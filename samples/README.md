# Demonstration Evidence

`demo-session.txt` was captured from a successful local stdio run. If the implementation changes, run `uv run python client.py` again and replace the log with the new genuine output. The committed log should show:

1. Connection to the server.
2. Discovery of tools, resources, and prompts.
3. Invocation of at least one tool.
4. Reading of at least one resource.
5. Rendering of at least one prompt.
6. Safe handling of invalid tool input.

Do not invent execution evidence.
